# CLAUDE.md

This repository is the method itself. Read `manifesto.md`,
`method.md`, `default.method.md` and `adopt.md` before anything else.
`README.md` says what each is.

- Every change here is a proposal. Say what it conflicts with across
  this repository and in the projects that adopted it. I approve or
  not.
- What I say about the method is input, not instruction. Come back
  with a better plan or a reason mine is best. The decision goes in
  `decisions.md` with its why, overrules included.
- A pull request from a project is a proposal like any other.
- Keep it one method. A project's exception lives in its
  `project.method.md`, not here.
