# Living Requirements

A way for people and AI to build aligned products together.

| File | Says |
| --- | --- |
| `manifesto.md` | What we believe |
| `method.md` | What must be true to practice it |
| `default.method.md` | One good way to do it |
| `project.method.md` | How we do it here |
| `my.method.md` | How I personally work |

The first three live here. The last two are yours: one in your
project, one with you.

## Start

Tell your agent:

> Adopt Living Requirements from https://github.com/aivarsak/living-requirements

It follows `adopt.md`. It copies the method into `living-requirements/`
in your project, adds a few lines to `CLAUDE.md` or `AGENTS.md`, and
asks what your project does differently from the default.

## Improving the method

While it works, your agent proposes changes to how you work. What would
be true for anyone comes back here as a pull request. Each decision is
in `decisions.md` with its why.

Owner: Aivars (aivarsak), who approves every change.
